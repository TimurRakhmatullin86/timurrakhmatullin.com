Rust · Python · Node.js

Multi-layer prompt injection detection library. Rule-based scanning at 11.9μs per input — no ML model required. Ships as a Rust crate, Python package (PyO3), and npm package (napi-rs) with middleware for FastAPI and Express.

LogCompress

Rust

Semantic log compression for incident investigation. Achieves 100% recall on benchmark (55/55 queries, 5 incident types) with trace-aware expansion that pulls all related log lines by trace ID. Parallel tokenization via Rayon.

CodeShrink

Rust · Node.js

Code-aware context compressor for LLMs. Extracts function signatures while discarding implementation details — 99.9% compression on large codebases (1.29M LOC → 1.5K in 2.8s). Helps fit entire repositories into LLM context windows.
