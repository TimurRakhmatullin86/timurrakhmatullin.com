## Опенсорс-проекты

### TraceShrink
- URL: https://github.com/TimurRakhmatullin86/traceshrink
- Язык: Go
- Описание: Cost-aware процессор для OpenTelemetry Collector. Сохраняет дорогие трейсы, отбрасывает дешёвые — экономия до 98% на хранении. Включает процессор аннотации стоимости LLM-спанов для 2764 моделей.
- Производительность: 1.84M спанов/сек

### PromptFirewall
- URL: https://github.com/TimurRakhmatullin86/promptfirewall
- Языки: Rust, Python (PyO3), Node.js (napi-rs)
- Описание: Многослойная библиотека детекции prompt injection. Rule-based сканирование — без ML-модели. Мидлвари для FastAPI и Express.
- Производительность: 11.9мкс на сканирование, 149 тестов
- Пакеты: crates.io, PyPI, npm

### LogCompress
- URL: https://github.com/TimurRakhmatullin86/logcompress
- Язык: Rust
- Описание: Семантическое сжатие логов для расследования инцидентов. Trace-aware разворачивание собирает все связанные строки по trace ID.
- Производительность: 100% recall на бенчмарке (55/55 запросов, 5 типов инцидентов)

### CodeShrink
- URL: https://github.com/TimurRakhmatullin86/codeshrink
- Языки: Rust, Node.js (napi-rs)
- Описание: Code-aware компрессор контекста для LLM. Извлекает сигнатуры функций, отбрасывая реализации — 99.9% сжатия (1.29M LOC → 1.5K за 2.8с).

### MCP-Drill
- URL: https://github.com/TimurRakhmatullin86/mcp-drill
- Язык: Python
- Описание: Fault injection и тестирование контрактного соответствия MCP-серверов. Генерирует скоркарды соответствия.
